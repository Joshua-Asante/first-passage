## Guardrail 1 — domain-conflation

A mechanism's declared single pipeline stage must match its actual functional reach (inputs and outputs, not just its label). If its stated purpose is to inform a decision that belongs to a different named stage, it is conflating altitude — the GRAND/Quintessentials precedent, one register smaller.

Before proposing new machinery, check whether the repo already has a same-shaped tool under its own name (`gate-reachability-audit`, `pre-ratification-adversarial-panel`, `verify-source`, the c1 arming interlock) that the proposal would reinvent under imported vocabulary.

## Guardrail 2 — evidentiary-substitution

If a proposed mechanism's core action is an LLM re-prompt, tag, write-up, or debate that produces a number or label which then feeds or weighs on any existing gate, the anti-substitution safeguard must be engineered into the *operative logic* and must route through an independently-runnable deterministic computation wherever one already exists. Narrating the number is not the check.

A "disclosed but not gating" posture does not neutralize this if the disclosed number is the sole input a fixed investigative budget is reallocated on.

## What a survivor looks like

A proposal that would survive looks boring in pipeline-native terms: a one-line addition to an existing deterministic check, with zero LLM judgment on the decision path.
