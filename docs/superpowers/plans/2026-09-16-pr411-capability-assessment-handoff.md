Each S/R/N row contains requirement/consuming contract; actual producer and entitlement; account/environment/route binding; effective/published/captured times; query bounds, timezone, coverage, ordering, corrections and retention; original-byte digests; code/config identities; actual consumer result; verdict; exactly one next disposition. Public records use non-sensitive references and permitted digests, not account values or private paths.

Use four verdicts:

- `QUALIFIED`: source semantics and actual evidence satisfy the named account/route/use, and its applicable consumer has accepted the evidence.
- `UNPROVEN`: evidence or access is missing; specify the precise fact and one next acquisition/test.
- `UNSUPPORTED`: demonstrated incompatibility within the examined scope; do not infer it merely from an empty query.
- `AMENDMENT_REQUIRED`: an alternative requires a change to the governing semantics; document the exact delta and effects without adopting it.

Keep documentary evidence, actual nonempty observations and synthetic consumer tests distinct. Record measured operator effort and usable evidence latency; otherwise state unknown. Successful collection is not successful reconciliation.
