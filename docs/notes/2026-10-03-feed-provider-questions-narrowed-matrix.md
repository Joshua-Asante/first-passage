**Companion of:** [2026-10-03-feed-provider-questions-narrowed-DRAFT.md](2026-10-03-feed-provider-questions-narrowed-DRAFT.md). That note holds the summary, the conflicts, the open licensing assumptions and the drafts. This file holds the row-level evidence.

**Retrieval:** every source below was retrieved on **2026-10-03** with WebSearch and WebFetch. No login, form, account, trial or contact.

## How to read a row

- **Labels.** [page] = the page was fetched and read. [pdf] = the PDF was fetched and read. [excerpt] = a search-result excerpt only; the page was not opened. [3p] = a third party (forum, another broker, open-source client); never a sourced fact for licensing.
- **Paraphrase, not quotation.** Facts are paraphrased with a section or clause locator so Joshua can find the exact wording. The fetch tool returns a model extraction of each page, so even its "quotes" can drift. Read the governing text at the URL before relying on any wording.
- **Licensing and eligibility rows are never marked answered** unless an official source states the right explicitly for this use: an individual non-professional, automated non-display decisions, orders at another broker in a prop-firm evaluation account.
- **CME documents cited as [excerpt] in provider sections** (CME-FAQ, CME-S5, CME-FL, CME-UPD) were later read in full; the CME section (CM1–CM8, [pdf]) holds the page-verified text and supersedes those excerpts.
- **Residual question** = the smallest wording still needed. "none" = answered by source. A negative answer counts as answered when the source is explicit.
- Status codes used in the summary: **D** dropped (answered by source), **N** narrowed (partly answered; a smaller question remains), **F** asked in full (nothing relevant found from the provider).
