# Introduction to Python: six-week study plan

Study window: October 15–November 25, 2026 (America/New_York).
Goal: complete WGU Academy's recommended Udemy sections, prepare using zyBooks,
and take the final assessment within six weeks.

## Weekly schedule

Thirty study hours across six days, totaling 180 hours. Saturday is the proposed
study rest day. Work runs noon–9pm Monday–Thursday and Saturday.

| Day | Study blocks | Hours |
| --- | --- | ---: |
| Monday–Thursday | 9–11am; 9:30–11pm | 3.5 each |
| Friday | Four two-hour blocks, with breaks outside study time | 8 |
| Saturday | Study rest day | 0 |
| Sunday | Four two-hour blocks, with breaks outside study time | 8 |

Before work: recall previous material, learn new concepts, and code examples.
After work: solve 2–3 short problems independently, debug, and record the next task.
Friday: substantial coursework/project work plus matching zyBooks labs.
Sunday: cumulative practice, repair weak areas, and check progress against the
current week's milestone. Weekly milestones close Wednesday; Thursday starts
the next study week.

For each eight-hour day, use four blocks:

1. Recall and lessons.
2. Exercises, attempting each before viewing its solution.
3. Independent project work.
4. Testing, debugging, and review.

## Daily completion and assessment readiness

Count a topic as complete when you can write a small example from a blank file,
explain it, and fix a mistake in it. Video completion alone is insufficient.
Record completed sections/labs, unresolved errors, and tomorrow's first task.

Check every practice answer:

- Return or print exactly as requested.
- Match the required value, type, order, and output whitespace.
- Check range and slice boundaries.
- Use supplied imports appropriately; practise help() and dir() as described
  in the enrolled course's exam tips.
- Test different arguments and relevant edge cases; avoid hard-coded answers.

Suggested readiness target: at least 90% of available practice points on two
separate independent sessions, including fresh variations. This is a planning
target, not WGU's official passing threshold. For assessment simulations, use
only resources confirmed as permitted in the enrolled exam instructions.
