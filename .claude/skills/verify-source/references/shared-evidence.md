# Shared evidence-family guidance

This optional reference is for tasks that cross `verify-source`,
`handoff-verify`, and `fable-judge`, or that need a reuse decision. Each skill's
own file remains sufficient for its single-skill workflow.

## Stance and routing

A borrowed value, an external instruction packet, and a completed-work report
are claims, not evidence. Detail, internal consistency, and agreement with a pin
do not establish currency or correctness.

| Task shape | Skill |
|---|---|
| Quote or decide from a borrowed value, premise, cohort, or artifact | `verify-source` |
| Execute an external packet that asserts repository state | `handoff-verify` |
| Judge work that another actor claims is complete | `fable-judge` |

Use every row that actually applies, but none merely because the family exists.
Plain local work with no borrowed premise, external packet, or completed-work
claim activates none of these skills. Rule 0 remains the read-production-first
precondition; statistical validity and scope or authorization controls remain
with their existing owners.

## Reuse and refresh

Reuse evidence only while its source or target and revision, the claim it backs,
its scope, and relevant state remain unchanged. A relevant edit, completed
implementation, new external claim, moved comparison base, or uncertainty makes
the affected evidence stale; refresh it before use. Task activity alone does not
invalidate unrelated facts, so do not repeat unaffected checks.

Reuse never replaces a selected skill's substantive checklist, stop condition,
or output marker.
